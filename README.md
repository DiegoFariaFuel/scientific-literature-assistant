# SciLit — Bilingual Scientific Literature Assistant

An evidence-oriented NLP/LLM application for exploring a researcher's own scientific PDF corpus. It combines multilingual dense retrieval (E5 embeddings), lexical BM25 search, reciprocal-rank fusion, optional cross-encoder reranking, and answers from a locally served LLM with paper and page citations. A retrieval evaluation command reports Recall@k and mean reciprocal rank on researcher-labeled questions.

The software is a literature navigation aid, not a systematic review, medical device, or substitute for reading and appraising the original papers. No papers, embeddings, answers, or evaluation scores are bundled. Scanned PDFs need OCR before indexing. Verify generated summaries and citations against the source.

## Architecture

1. PyMuPDF extracts text page by page from PDFs supplied locally by the researcher.
2. Text is split into overlapping page-bounded chunks; paper title, DOI, year, page, and stable source ID are retained.
3. A multilingual E5 sentence transformer indexes the chunks. BM25 supplies a separate lexical ranking; reciprocal-rank fusion combines the lists. A Sentence Transformers CrossEncoder can optionally rerank the candidate set.
4. The top evidence chunks are sent to a local Ollama chat endpoint. The prompt requests source-grounded claims, page citations, uncertainty when evidence is missing, and treats paper text as untrusted data.
5. Retrieval evaluation measures Recall@k and MRR against a manually labeled JSONL set. These metrics evaluate retrieval only, not answer correctness or scientific validity.

## Install

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[api]'
```

The embedding model is downloaded by Sentence Transformers on first use. The default is `intfloat/multilingual-e5-small`; E5 inputs use the `query:` and `passage:` prefixes. For offline or controlled environments, pre-cache the model and configure `SCILIT_EMBED_MODEL` to its local directory.

Install and start Ollama separately, then configure a model available in that local Ollama instance using `OLLAMA_MODEL`. The application calls the local `/api/chat` endpoint by default and has no hosted LLM integration enabled.

## Index a local corpus

Put PDFs under `data/papers/`. Optional adjacent metadata files use the same base name, for example `paper.pdf` and `paper.json`; see [`examples/metadata.sample.json`](examples/metadata.sample.json). DOI is also detected from the first two pages when available.

```bash
scilit ingest --pdf-dir data/papers --index-dir index
```

The local `data/` and `index/` contents are ignored by Git so papers and embeddings are not published by accident.

## Ask with cited evidence

```bash
scilit ask "Quais métodos de validação foram usados nos estudos?" --index-dir index --top-k 5
```

The answer follows the language of the question and returns cited sources with titles, DOI when available, page numbers, and the retrieved excerpts. You can select an optional local reranker with `SCILIT_RERANK_MODEL` or `--reranker MODEL_NAME`.

## Evaluate retrieval

Create a JSONL file with one object per manually reviewed question. Each `relevant_source_ids` value must match the `source_id` field in the local `index/chunks.jsonl` file. A schema example is in [`examples/evaluation.sample.jsonl`](examples/evaluation.sample.jsonl).

```bash
scilit evaluate --cases data/evaluation.jsonl --index-dir index --top-k 5
```

Report corpus composition, question-labeling method, embedding/reranker model, and `k` with any results. Do not present retrieval scores as answer-accuracy scores.

## Local API

```bash
scilit-api
```

By default, the API listens on `127.0.0.1:8080`. `GET /health` reports whether an index exists; `POST /ask` accepts `{"question":"...", "top_k":5}`. The API uses the same local LLM setup as the CLI. Add authentication and transport security before exposing it beyond the local machine.

## Privacy, provenance, and limitations

- Source PDFs, extracted passages, and vector indexes remain on disk under the configured local paths. The default LLM destination is a local Ollama server; changing `OLLAMA_BASE_URL` can send retrieved passages elsewhere.
- Keep copyright and license terms in mind when collecting papers. This tool indexes files you provide and does not redistribute them.
- PDF extraction can omit tables, figures, equations, or reading order. OCR quality and PDF structure affect retrieval.
- Citations are generated by an LLM and may be missing or misapplied. Always open the cited pages and verify every important claim.
- A local knowledge base may be incomplete or biased; absence of a retrieved passage is not evidence that no study exists.
- No training or fine-tuning is performed. The project uses pretrained components and local inference.

## Português

Assistente de literatura científica com NLP e LLM para explorar uma coleção local de PDFs. Combina busca semântica multilíngue por embeddings E5, busca lexical BM25, fusão por reciprocal-rank fusion, reranking opcional com CrossEncoder e respostas de um LLM local com citações de artigo e página. Inclui avaliação reproduzível da recuperação com Recall@k e MRR a partir de perguntas rotuladas pelo pesquisador.

O software ajuda a navegar a literatura; não substitui a leitura crítica, não constitui revisão sistemática e não é dispositivo médico. Não há artigos, embeddings, respostas ou métricas de avaliação no repositório. PDFs digitalizados precisam de OCR. Confira as respostas e referências nas páginas originais.

Instale com `python -m pip install -e '.[api]'`. Coloque os PDFs em `data/papers/` e indexe com `scilit ingest --pdf-dir data/papers --index-dir index`. O modelo multilíngue de embeddings é baixado no primeiro uso; o padrão é `intfloat/multilingual-e5-small`. Os dados locais em `data/` e `index/` são ignorados pelo Git.

Configure e inicie uma instância local do Ollama e escolha nela o modelo por `OLLAMA_MODEL`. O projeto usa o endpoint local `/api/chat` por padrão e não está conectado a um serviço de LLM hospedado. Para perguntar: `scilit ask "Quais métodos de validação foram usados?" --index-dir index`. A resposta segue o idioma da pergunta e lista as fontes recuperadas com página, trecho e DOI quando disponível.

Para avaliar a busca, crie JSONL com perguntas e `relevant_source_ids` copiados do índice local, seguindo `examples/evaluation.sample.jsonl`, e execute `scilit evaluate --cases data/avaliacao.jsonl --index-dir index --top-k 5`. Recall@k e MRR avaliam apenas a recuperação, não a correção científica das respostas.

Os PDFs e índices permanecem nos caminhos locais configurados. Alterar `OLLAMA_BASE_URL` pode encaminhar trechos recuperados a outro servidor. Respeite licenças e direitos autorais. A extração de PDF pode perder tabelas, figuras e equações; o LLM pode omitir ou atribuir incorretamente citações. Verifique afirmações importantes diretamente nos artigos. O projeto usa componentes pré-treinados e inferência local; não treina nem ajusta modelos.
